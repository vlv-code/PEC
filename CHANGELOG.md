# Журнал изменений (CHANGELOG)

Все заметные изменения в проекте **PEC - Proxy Extension Corp** документируются в этом файле.

## [v1.3.1] - 2026-09-23

Security & correctness release по итогам полного code review.

### 🔴 Критические исправления
- **CRX3 вместо CRX2**: пакеты `.crx` подписываются в формате CRX3 (protobuf + RSA-SHA256) — Chrome 70+ отказывался от CRX2, центральная фича продукта не работала. Реализация побайтово сверена с эталонным пакетом `crx3`.
- **Авторизация админ-API**: все management-эндпоинты (`/api/builder/*`, `/api/routing/*`, `/api/rotation/*`, `/api/instances/*`, `/api/config`, `/api/status`) теперь требуют `X-Ext-Token`. Ранее `GET /api/extension/info` отдавал токен в GPO-конфиге, а `GET /api/rotation/config` — пароль 3x-ui в открытом виде; авторизация обходилась одним GET-запросом.
- **Токен убран из HTML дашборда**: вход по токену (sessionStorage), 401 автоматически повторно запрашивает авторизацию.
- **PAC-инъекция через имя правила**: санитизация `rule.name` (ранее экранировались только `profile.name` и хост) + sinkhole без DIRECT-fallback («блокировка» трекеров реально блокирует).
- **Stored XSS в консоли**: экранирование всех интерполяций в innerHTML-рендерах (флот, аудит, правила, релизы) + CSP-заголовок.
- **Ротация без silent desync**: при недоступном 3x-ui креды НЕ меняются локально (ранее флот тихо ломался при `success: true` в истории).
- **Docker-сборка**: закоммичен `package-lock.json` (`npm ci` падал без lock-файла), runner-stage урезан до prod-зависимостей, всё состояние вынесено в том `/app/data` (ранее редеплой обнулял профили и ротацию).
- **systemd-установка**: добавлен `npm run build` (сервис уходил в рестарт-луп из-за отсутствия `dist/`).

### 🟠 Существенные исправления
- Расширение: `background.js` генерируется из шаблона с подстановкой настроек студии (Server URL, токен, интервал синка, таймаут bypass, группа); «Временно отключить (15м)» теперь реально включается обратно по alarm; IP-чекер использует абсолютный URL; `managed_schema.json` объявляет `targetGroup`; `minimum_chrome_version` 108.
- CORS: строгое сравнение Origin с Host (ранее `includes("")` при пустом Host открывал CORS всем).
- Rate limiter: доверие `X-Forwarded-For` только при `TRUST_PROXY` (env), единая логика client IP.
- Интервал ротации валидируется (NaN/0 ранее превращались в 1-мс шторм).
- Instances: O(1) LRU, защита от prototype pollution, лимит `instances_meta.json`, `DELETE /api/instances/:id`.
- Дашборд: kill-switch синхронизируется с сервером; ошибки сохранения видны (ранее — молчаливые «удачные» save); новый профиль сразу сохраняется на сервер; Test Sync чистит за собой тестовый инстанс; alert() заменены тостами.
- `PUBLIC_BASE_URL` против Host-header poisoning артефактов (updates.xml, GPO).
- Начальный пароль кредов — случайный (был захардкожен в двух местах).

### 🧪 Тесты и инфраструктура
- Тесты изолированы в temp-каталогах (ранее мутировали прод-сторы; в git было закоммичено 11 дублей тестового профиля и тестовый `proxy_config.json` с мёртвым прокси). 13 → 31 тест: HTTP-авторизация, CRX3-структура и подпись, PAC-инъекции, ротация, instances.
- Runtime-файлы (`rotation_config.json`, `proxy_config.json`, `routing_profiles.json`, `extension_build_config.json` и др.) убраны из git и добавлены в `.gitignore`.
- GitHub Actions CI (lint + test + build).
- `.env.example` в корне репозитория (ранее README ссылался на несуществующий файл).
- Chrome 108+ как минимальная версия расширения.

## [v1.3.0] - 2026-09-22

### 🚀 Основные изменения и новые функции
- **Ребрендинг**: проект переименован в **PEC - Proxy Extension Corp**.
- **Локализация**: добавлена полноценная поддержка русского языка в интерфейс панели управления, конструктор расширений и всплывающее окно (popup) расширения Chrome.
- **Сценарии развертывания сервера**:
  - Добавлен официальный `Dockerfile` (multi-stage Alpine Linux, non-root пользователь `pecuser`, healthcheck, dumb-init).
  - Добавлен `docker-compose.yml` и production-вариант `docker-compose.prod.yml` с поддержкой Nginx.
  - Создана директория `deploy/` со скриптами автоматической установки:
    - `deploy/install-docker.sh`
    - `deploy/install-systemd.sh`
    - `deploy/pec-server.service`
    - `deploy/nginx-proxy.conf`
    - `deploy/install-standalone.sh`
  - В веб-панель управления добавлена интерактивная вкладка **«Сценарии установки & Docker»** с готовыми конфигурациями и командами копирования.
- **Интерактивный Live Extension Preview и Симулятор**:
  - Исправлено переключение вкладок внутри preview sandbox: глобальный обработчик `window.switchPopupTab` и прямой перехват кликов по `.tab-btn` гарантируют плавную смену вкладок без сбоев.
  - Исправлен симулятор состояний (**Simulated Extension State**): переключение между режимами "Online Proxy", "Bypassed", "Offline Fallback" и "Re-Authenticating" теперь отправляет реактивные `postMessage` без разрушения DOM и без сброса активной вкладки.
  - Обеспечено обновление бейджа браузера и индикаторов в реальном времени.

### 🛡️ Безопасность и надежность
- Реализован строгий санитайзинг доменов, шаблонов и CIDR-диапазонов в функции генерации `FindProxyForURL` (`pac.js`), исключающий XSS и PAC script injection.
- Добавлена защита от path traversal при чтении и сохранении исходного кода расширений.
- Добавлено авто-восстановление файла хранилища учетных данных `current_creds.json` при сбоях или удалении.
- Внедрен Rate Limiting в конфигурацию Nginx для предотвращения атак перебора токена авторизации.

### 📦 Инфраструктура репозитория
- Настроен чистый `.gitignore` с защитой приватных ключей, секретных файлов окружения и артефактов.
- Подготовлен релизный тег `v1.3.0`.
